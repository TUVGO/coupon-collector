# Security policy

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities, leaked credentials, authentication flaws, or privacy problems. Contact the future repository owner through a private security channel. A public security contact must be added before release.

## Sensitive data

Never commit access tokens, cookies, QR login sessions, device identifiers, user locations, order details, credentials, or production logs. If sensitive data is committed, revoke or rotate it first; removing it from the latest commit is not sufficient.
