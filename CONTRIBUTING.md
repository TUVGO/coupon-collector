# Contributing

This project is not open for public contributions until the release review is complete.

For approved internal preparation work:

1. create a focused branch;
2. never commit credentials, tokens, cookies, customer data, location history, or production logs;
3. keep production network operations out of tests;
4. run `node --check scripts/run.js` and `python -m py_compile scripts/auth.py`; and
5. document any new API, dependency, or asset and its redistribution license.
